# Lessons from merged work

What merged work got wrong, and the rule that would have caught it. Read
this before changing code.

Each lesson is a rule, then why, then the evidence: the commits or issues
that show it. "Seen" counts the separate days a review found it. A lesson
seen on three days moves into [docs/code-standards.md](docs/code-standards.md)
and is listed under [Moved to the code standards](#moved-to-the-code-standards).

A lesson is written when a fix had to be fixed again, when something merged
that shouldn't have, or when a check was thinner than the change needed.
