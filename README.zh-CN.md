# Crossbill（交嘴雀）

[English](README.md)

Crossbill 盯着多条链和能带动行情的人，有值得一看的事就通知你；你打开交易之后，它还能用替你保管的钱包、在你设定的上限内下单。

> **状态：设计阶段。** 目前还没有可运行的代码。下面的文档是已经定下来的设计，代码会照着写。

## 做什么

- **探测**机会：名人发帖后几分钟内冒出的同名币、池子成交量或持币人数突然放大、上币公告、资金费率明显偏离正常。
- **过滤**：先做代币安全检查，再由大模型按你写下的关注点打分。每天几千条事件，最后只剩几条。
- **通知**：推送到 Telegram 和 Bark，每种消息类型推到哪些通道由你选。
- **事后跟踪**：每个机会在 1 小时、6 小时、24 小时后自动记录价格，用来判断哪些信息源和规则值得跟。
- **交易**（需你手动打开）：用加密保存的各链子弹钱包下单，签名器会拒绝任何超出上限的交易。

支持的链：EVM（BSC、Base、Ethereum、Arbitrum 等）、Solana、Tron。

## 默认行为

- 只探测，不交易。交易要你手动打开并设好上限才生效。
- 后台只监听 `127.0.0.1`。要开放到网络上，必须带访问密钥。
- 除了你自己配置的 RPC、数据源、模型接口和通知通道，Crossbill 不往任何地方发数据。
- 所有 Key 都由你自己提供：数据接口、模型接口、机器人 Token。

## 不构成投资建议

Crossbill 是工具。它发现信号、执行操作，但不判断信号好不好。绝大多数新币最后归零。它能接入的部分服务在一些国家和地区不可用，使用前请先确认。
